## v0.2.0-alpha.1 - 2026-05-09 UTC

- Alpha release for the Lethal Company v81.5 compatibility update.
- Added structured validation logging for release checks. It is disabled by
  default and avoids player names, lobby identifiers, account identifiers,
  machine names, profile paths, access or session tokens, and raw Unity object
  details.
- Added Harmony callback diagnostics that report compact exception type
  metadata without breaking base-game callbacks if diagnostics fail.
- Updated package compatibility documentation for the Lethal Company v81.5 and
  BepInExPack v5.4.2305 baseline.
- GitHub-only prerelease artifact. This alpha is not published to Thunderstore,
  and real-game validation is tracked separately in #11.
